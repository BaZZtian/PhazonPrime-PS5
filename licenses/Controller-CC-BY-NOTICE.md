# DualSense prompt artwork

Based on "Playstation 5 Dualsense" by AHarmlessPotato.
Source: https://sketchfab.com/3d-models/playstation-5-dualsense-878c1f882808477ab81c2fe86d5a3936
Author: https://sketchfab.com/AHarmlessPotato

The supplied archive license and GLB metadata both identify this author and
license. The online model page was inaccessible during this audit.
Modifications: disconnected component extraction, orthographic rendering with
source base-color textures and authored lighting, stick cap translation,
directional petal tint, and independently typeset shoulder labels for readability.
No animation was supplied by the model author. The directional sequences are
authored derivatives. Font labels use Arial Bold from the local render host;
no font file is distributed. This notice does not license Sony trademarks.
Original archives and generated binary artwork remain local in this work step.
