# 00.001.035

Restore original shell artwork and publish locally generated tile music into own registered metadata.

# Changelog

## v00.001.000 - 2026-11-01

- Native PS5 application for the supported PAL Metroid Prime disc profile.
- DualSense controls, PlayStation prompts and language/settings menus.
- Three regular save slots and separate positional autosave records.
- Menu Quit, PS5 model preview and graphics/projectile corrections.
- Local tile-music generation from your own game data.
- MathPhazon and StoragePhazon with preserved component licenses and matching corresponding source.

Known Issues: invisible map geometry and visually closed passable doors. Full-game completion and universal firmware/loader compatibility are not claimed. System-menu tile-music playback has not been verified for this release.
